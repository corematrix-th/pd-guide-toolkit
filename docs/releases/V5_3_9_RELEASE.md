# PD Guide Toolkit v5.3.9

- Added Battery Health Calculator tab with monitor-style battery icon.
- Inputs: Design Capacity and Full Charge Capacity in the same unit.
- Output: Full Charge Capacity / Design Capacity * 100, displayed to one decimal place.
- Input validation and clear controls; no replacement decision or thresholds.
- Increased completed Checklist row contrast in Light Theme.
- Existing modules and Dark Theme remain unchanged.

- Both calculators list Design Capacity before Full Charge Capacity.

- Below-50% Email TH added to both calculator surfaces without changing any repair or warranty rule.
- Preserved the existing >=50% popup email template.
